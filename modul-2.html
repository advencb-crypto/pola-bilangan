Tahap 2 • Anti-Hafalan Buta (Discovery Learning)

Menemukan Sendiri Rumus Suku ke-n: Un = a + (n − 1)b

🎯 Misi: Tebak jumlah panah ke U₁₀ & U₁₀₀ untuk membuka rumus

Perhatikan panah lengkung pada garis bilangan di atas! Untuk melangkah dari suku pertama (U1 = a) menuju suku tertentu, kita tidak perlu menghafal rumus terlebih dahulu—cukup hitung ada berapa banyak panah loncatan (b) yang dilewati.

Suku ke-n Banyak Panah Loncatan dari U1 Pola Penjumlahan Beda Bentuk Aljabar
U1 (n = 1) 0 loncatan a (belum melompat) a + (1 − 1)b = a + 0b
U2 (n = 2) 1 loncatan a + b a + (2 − 1)b = a + 1b
U3 (n = 3) 2 loncatan a + b + b a + (3 − 1)b = a + 2b
U4 (n = 4) 3 loncatan a + b + b + b a + (4 − 1)b = a + 3b
U5 (n = 5) 4 loncatan a + b + b + b + b a + (5 − 1)b = a + 4b
🔑 Kunci Pembuka Rumus Utama

Lihat polanya: untuk ke U2 butuh 1 loncatan, ke U3 butuh 2 loncatan, ke U5 butuh 4 loncatan. Sekarang tebak dua pertanyaan ini untuk membuka kartu rumus!

🎉 Rumus Barisan Aritmetika Berhasil Ditemukan! Konsep: Loncatan = (n − 1)
Un = a + (n − 1)b

Mengapa dikali (n − 1) dan bukan n? Karena kita sudah berdiri di suku pertama (a = U1). Untuk mencapai urutan ke-n, kita hanya perlu melompat sebanyak (n − 1) kali sejauh b! Misalnya ke U100, cukup dari U1 ditambah 99 kali beda (99b).
